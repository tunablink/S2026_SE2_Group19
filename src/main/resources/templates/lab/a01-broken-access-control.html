Lab 2

Fix with middleware, ownership checks, and retest

Defense

Vulnerable handler

The bug exists because the handler trusts the account ID path parameter and returns the object before checking whether the current user owns it. 

GET /api/accounts/:accountId/statement

function getStatement(req, res) {
  const statement = statementRepo.findByAccountId(req.params.accountId);
  return res.json(statement);
}
  • Add a server-side authorization step before returning the statement.
  • Compare the loaded account owner with the authenticated user.
  • Retest ACC-102 as Linh and expect 403 Forbidden.
